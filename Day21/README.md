# Day 21 - Launch EC2 Instance and Associate Elastic IP (AWS Console)

## 📌 Objective

Provision a new EC2 instance and associate an Elastic IP address to ensure a stable public IP for application hosting.

### Requirements

- EC2 Instance Name: `devops-ec2`
- AMI: Any Linux AMI (e.g., Ubuntu)
- Instance Type: `t2.micro`
- Elastic IP Name: `devops-eip`
- Region: us-east-1

---

## 🌍 AWS Environment Details

- Service Used: Amazon EC2
- Region: us-east-1
- Instance Type: t2.micro
- Public IP Requirement: Elastic IP (static)

---

## 🚀 Implementation Steps (Using AWS Console)

### Step 1: Login to AWS Console

- Open the provided Console URL
- Login using given credentials
- Ensure region is set to **us-east-1**
